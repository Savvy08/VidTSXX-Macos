# Создание автономного установщика VidTSX.dmg

- **Ветка:** main
- **Заголовок:** Полная изоляция зависимостей и сборка релизного DMG-образа с белым фоном
- **Причина:** Необходимость распространять программу без привязки к системе и хорошая читаемость стрелки в окне
- **Реализация / Что сделано:**
  1. Все ресурсы (движок Node.js, веб-плеер React+Babel, иконки, конфиги) вшиты внутрь бандла VidTSX.app/Contents/Resources.
  2. Фон окна установщика переведен в чистый белый (#FFFFFF) с четкой контрастной темно-графитовой стрелкой по центру, без текста и водяных знаков.
  3. Обновлены права доступа к файлу фона и исправлена команда AppleScript для корректного отображения картинки в окне Finder.
  4. Собран финальный сжатый образ build/VidTSX.dmg (31 МБ).
- **Результат:** Установщик VidTSX.dmg открывается со светлым контрастным фоном и четко видимой стрелкой для перетаскивания.
