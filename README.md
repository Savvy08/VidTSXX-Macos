<h1 align="center">VidTSX for macOS</h1>

<p align="center">
  Native macOS app to preview React Remotion TSX video compositions and render them directly to MP4 with hardware acceleration.
</p>

## Features

- Instant Import: Drag and drop `.tsx` files or paste Remotion code directly from the clipboard.
- 60 FPS WebKit Preview: Smooth real-time playback matching the composition frame rate, with interactive timeline scrubbing.
- Hardware-Accelerated Export: Direct MP4 encoding using native VideoToolbox with zero cloud dependencies.
- 100% Standalone: Self-contained runtime bundled inside the app, works offline out of the box.
- Resource & Thermal Management: Configurable CPU modes (Eco, Balanced, Max), background QoS priority, and memory limits.
- Multilingual: Automatically follows macOS system language, with manual English and Russian switching.

## Installation

1. Download `VidTSX.dmg` from the Releases section.
2. Open the DMG and drag `VidTSX.app` into your `Applications` folder.
3. Launch the app and drop any Remotion `.tsx` composition to preview and render.
