<h1 align="center">VidTSX for macOS</h1>

<p align="center">
Native macOS app for working with .tsx files and exporting them to MP4.
</p>


### Features
- **Code Import**: Paste TSX code directly into the app or drag and drop files.
- **Hardware Export**: Video rendering runs directly through Apple VideoToolbox.
- **System Load Profiles**: Eco, Balanced, and Maximum modes for resource control (useful for MacBook Air).
- **Bilingual**: English and Russian interface with system language auto-detection.

### Requirements
Requires macOS 14.0 or later


### Installation
1. Download `VidTSXX.dmg` from the [Releases](https://github.com/Savvy08/VidTSXX-Macos/releases) page.
2. Open the disk image and drag `VidTSXX.app` into your Applications folder.


### Build from Source
```bash
./Scripts/build_app.sh
```
